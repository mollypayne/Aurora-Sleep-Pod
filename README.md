## Aurora Pod

The 'Aurora Pod' is an accessibility-first project exploring how to design a personal sleep-pod environment around the accessibility needs of disabled students in University dorms.
This project combines embedded electronics, environmental monitoring, accessible physical design and user-focused testing within a student-feasible prototype.

## Project Objectives

- Design an accessible sleep-pod concept
- Explore environmental monitoring
- Prototype embedded control features
- Record and analyse sensor data
- Document design decisions, testing and development

## Planned Features

The current design includes:

- Temperature and humidity monitoring
- Accessible physical controls
- Environmental data logging
- Bed-level alignment monitoring
- Accessible entrance controls
- Equipment and personal-item storage
- Cable pass-through openings
- Adjustable ventilation and environmental feedback

However, final features may vary due to design constraints.
